# 🏥 Smart Healthcare & Diabetes Risk Analytics Dashboard

This is an **Interactive Healthcare Analytics Dashboard** designed using Tableau and hosted live via GitHub Pages. The project analyzes the relationships between clinical biometrics, patient demographics, and lifestyle habits to uncover insights into diabetes and cardiovascular health risks.

## 🌐 Live Project Link
You can interact with the live dashboard here:
👉 **[Live Healthcare Dashboard](https://github.io)**

## 📊 Key Dashboard Features
The project features a comprehensive **9-sheet dashboard** arranged in a clean, logical **3-tab story layout**:

* **Executive Health Dashboard:** A unified, single-screen view combining all 9 clinical and lifestyle charts.
* **Demographics Analysis:** An overview of gender distribution and age-wise patient metric segmentation.
* **Clinical Insights:** A deep-dive exploration of glucose levels, BMI, and their correlation with diabetes incidence.
* **Lifestyle & Advanced Risks:** A color-coded heatmap tracking the combined impact of smoking, alcohol, and low exercise on the overall Health Risk Score, alongside an age-wise side-by-side bar chart for heart disease and stroke risk.
* **Symptom Matrix:** A clean text table mapping the co-occurrence of symptoms (Chest Pain, Dizziness, Fatigue) against total blood pressure and cholesterol levels.

## 🛠️ Tools & Technologies Used
* **BI Tool:** Tableau Public (Data visualization, dashboarding, and story flow)
* **Hosting & Deployment:** GitHub & GitHub Pages (Live web portfolio hosting)
